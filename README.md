# tide
潮汐グラフ

釣り場ごとに、潮汐グラフ、満潮・干潮の時刻、日の出・日の入りを表示するページです。

- 潮位データ（広島・松山・呉、2026〜2027年）は `index.html` の中に入っています。出典は気象庁の潮位表です。
- 釣り場の名前、基準港、時間差・潮位差、位置は、見ているブラウザの中にだけ保存されます。
- 1回オンラインで開くと、`sw.js` がページを端末に保存し、電波がない場所でも開けます。電波があるときは最新版を取りに行き、3秒以内に取れなければ保存済みの版を表示します。
- ホーム画面に追加すると、アプリのように使えます（`manifest.webmanifest` とアイコン画像を使用）。
